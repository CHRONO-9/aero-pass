# AERO-PASS（エアロパス）
**無人航空機操縦士（一等・二等）学科試験 CBT模擬試験 × 体系スマート教科書 ＆ 国交省同期**

## 概要
「AERO-PASS」は、国土交通省「無人航空機の飛行の安全に関する教則」（現行：第5版）全6章に完全準拠した、**国家資格（一等・二等）学科試験 特化型Webプラットフォーム**です。

本番同様のCBT模擬試験（二等30分／一等75分タイマー・即時合否判定）、普遍的原則（Core Principle）＆版改訂差分を網羅した教則スマート教科書、航空局公式情報のリアルタイム改訂ウォッチャー、直前暗記チートシートを一元化し、学科試験の一発合格を強力にサポートします。

### 主要機能（学科試験 特化体系）
1. **💻 CBT模擬試験 ＆ スマート教科書ビューア（全30問・合否判定）**
   - 二等（30分）／一等（75分）のカウントダウンタイマー ＆ 合格基準80%即時合否判定。
   - 見直しフラグ（🚩）、問題パレット、3択選択肢、正誤判定＆解説。
   - 教則全6章フィルタ（第1・2章心得、第3章規則法令、第4章機体システム、第5章気象運航、第6章リスク管理、一等固有、改訂重点）。
   - 問題ごとに連動する「教則の普遍的原則（Core Principle）」「第5版現行基準根拠」「第4版旧基準からの差分」「試験対策ひっかけ回避Tip」。

2. **📖 教則全6章 体系スマート教科書 ＆ バージョン管理（v4 / v5 / v6拡張）**
   - 特定の改訂箇所だけでなく、第1章（操縦者の心得）〜第6章（運航リスク管理・SORA）の体系的カリキュラムを網羅。
   - 歴代（第4版）・現行（第5版）・将来（第6版拡張）の教則バージョン管理スキーマを実装。

3. **📡 国土交通省（航空局）公式HP リアルタイム改訂ウォッチャー ＆ 反映ステータス**
   - 航空局公式3大ページ（飛行ルール・技能証明・許可承認）を常時監視。
   - 教則・学科、実地基準、許可承認（DIPS2.0 / レベル3.5 / 4）、技能証明・更新などの最新通達（全9件）を学科教材へ即座に同期。

4. **⚡ 試験直前5分暗記！教則改訂一覧表 ＆ 頻出数値チートシート**
   - キーワードリアルタイム検索対応。
   - ① 第5版 改訂早見表（6項目）
   - ② 頻出数値カード（10枚）
   - ③ 一等公式秒殺シート（4枚）
