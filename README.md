# AERO-PASS（エアロパス）
**無人航空機操縦士（一等・二等）オールインワン実践シミュレーター（教則第5版準拠）**

## 概要
「AERO-PASS」は、既存の3択暗記アプリではカバーされていない**「実地試験（机上試験・口述試験・飛行日誌記入）」**および**「一等学科の計算問題・物理原理の視覚的学習」**を統合したWeb学習プラットフォームです。

### 5つのコアモジュール
1. **🗺️ 実地：机上試験マップ演習（20点満点）**
   - 用紙A（飛行計画・飛行経路図）の矛盾点・法令違反・RTH高度不備を4分以内に見抜くインタラクティブ演習。
2. **🎙️ 実地：口述試験AIロールプレイ ＆ 飛行日誌チェッカー**
   - 飛行前点検・異常事態・事故/重大インシデント報告の発声演習（100点持ち点減点方式）および飛行日誌3様式の記入漏れ検証。
3. **📐 一等：計算ビジュアライザー ＆ 無限ランダム生成ドリル**
   - 定常旋回（旋回半径・荷重倍数）、第1フレネルゾーン半径、揚抗比・水平到達距離の物理スライダー図解＋数値ランダム生成ドリル＋CBT画面内電卓。
4. **💻 学科：本番CBT完全再現モック × 教則第5版スマート差分ビューア**
   - 2026年7月14日適用の「教則第5版」改訂箇所（工業専用地域のDID除外、農薬空中散布の承認不要特例、技能証明更新期間など）を旧第4版と対比ハイライト。
5. **🏫 収益化エンジン（B2C買い切り ＋ 登録講習機関送客 ＋ B2BスクールLMS）**
   - 個人向け買い切り合格パス（二等 ¥1,980 / 一等 ¥2,980）
   - 「一発試験 vs 登録講習機関」診断によるスクール資料請求リード獲得（成果報酬モデル）
   - 全国のドローンスクール向け受講生進捗管理クラウド（B2B LMS）

## ディレクトリ構成
```text
aero-pass/
├── index.html   # メインアプリケーションUI（5モジュール統合）
├── styles.css   # コックピット計器風・高コントラストデザインシステム（Vanilla CSS）
├── app.js       # シミュレーター・物理演算・ランダム問題生成・採点ロジック
├── schema.sql   # PostgreSQL / Supabase マルチテナントDB設計（B2C + 送客 + B2B LMS）
└── README.md    # プロジェクト説明書
```

## ローカル起動方法
```bash
python3 -m http.server 8080
```
