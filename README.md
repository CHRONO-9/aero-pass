# AERO-PASS（エアロパス）
**無人航空機操縦士（一等・二等）オールインワン実践シミュレーター（教則第5版準拠）**

## 概要
「AERO-PASS」は、既存の3択暗記アプリではカバーされていない**「実地試験（机上試験・口述試験・飛行日誌記入）」**および**「一等学科の計算問題・物理原理の視覚的学習」**を統合したWeb学習プラットフォームです。

### 5つのコアモジュール
1. **🗺️ 実地：机上試験マップ演習（20点満点）**
   - 用紙A（飛行計画・飛行経路図）の矛盾点・法令違反・RTH高度不備を4分以内に見抜くインタラクティブ演習。
2. **🎙️ 実地：口述試験AIロールプレイ ＆ 飛行日誌チェッカー**
   - 飛行前点検・異常事態・事故/重大インシデント報告の発声演習（100点持ち点減点方式）および飛行日誌3様式の記入漏れ検証。
3. **📐 一等：計算ビジュアライザー ＆ 無限ランダム生成ドリル**
   - 定常旋回（旋回半径・荷重倍数）、第1フレネルゾーン半径、揚抗比・水平到達距離の物理スライダー図解＋数値ランダム生成ドリル＋CBT画面内電卓。
4. **💻 学科：本番CBT完全再現モック × 教則全6章スマート教科書 × 📡 国交省公式HPリアルタイム改訂ウォッチャー**
   - 2026年7月14日適用の「教則第5版（`002010809.pdf`）」改訂箇所（工業専用地域のDID除外、農薬空中散布の承認不要特例、技能証明更新期間、小型無人機等飛行禁止法の対象拡大など）を旧第4版と対比ハイライト。
   - 国土交通省（航空局）の3大公式ページ（`koku_tk10_000003.html` / `license.html` / `koku_fr10_000042.html`）から最新の通達・実地試験実施基準・審査要領改正を抽出し、カテゴリ別フィルタ・公式PDF直リンク・該当章ジャンプ機能を提供。
5. **🏫 収益化エンジン（B2C買い切り ＋ 登録講習機関送客 ＋ B2BスクールLMS）**
   - 個人向け買い切り合格パス（二等 ¥1,980 / 一等 ¥2,980）
   - 「一発試験 vs 登録講習機関」診断によるスクール資料請求リード獲得（成果報酬モデル）
   - 全国のドローンスクール向け受講生進捗管理クラウド（B2B LMS）

### 6名の専門エージェント体制（Autonomous Multi-Agent Team）
- `kyosoku_general_expert` : 無人航空機教則全般（第1章〜第6章・版管理対応）・実地試験スペシャリスト
- `physics_sim_engineer` : 航空力学・一等計算全9公式シミュレーターエンジニア
- `fullstack_b2b_architect` : 個人買い切り決済・学習履歴弱点分析・B2BスクールLMSアーキテクト
- `growth_leadgen_strategist` : 一発試験vsスクールROI診断・全国提携スクール送客・SEOマーケター
- `kyosoku_qa_auditor` : 教則全般・法規ファクトチェック＆品質監査官
- `mlit_regulatory_watcher` : 国交省公式情報リアルタイム調査・サイト反映スペシャリスト

│   ├── b2b_monetize.js                         # 個人弱点分析・買い切り決済・B2B LMS管理
│   └── growth_funnel.js                        # 給付金ROI診断・全国スクール検索・チートシート

│   └── mlit-regulatory-watch.yml               # 国交省公式HP定期監視ワークフロー（GitHub Actions）
├── schema.sql                                  # PostgreSQL / Supabase マルチテナントDB設計
