# AERO-PASS（エアロパス）
**無人航空機操縦士（一等・二等）オールインワン実践シミュレーター（教則第5版準拠）**

## 概要
「AERO-PASS」は、受験者の学習〜合格後の実務運航ライフサイクルに沿って、**「学科試験対策（全6章CBT・一等計算9公式）」「実地試験対策（机上試験・口述試験・飛行日誌記入）」「合格後実務（機体図鑑・カテゴリー自動判定・公的機関ポータル）」「スクールROI診断・B2B LMS管理」**を統合した **6本柱体制** のオールインワンWebプラットフォームです。

### 6つのコアモジュール（6本柱体制）
1. **💻 ① 学科：全6章CBT × 体系教科書 ＆ 📡 国交省公式HPリアルタイム改訂ウォッチャー**
   - 本番CBT試験モード切替（二等30分／一等75分カウントダウンタイマー＆80%合否判定バー）と教則全6章スマート教科書を統合。
   - 2026年7月14日適用の「教則第5版（`002010809.pdf`）」改訂箇所を旧第4版と対比ハイライトし、国土交通省（航空局）公式3大ページの最新通達・審査要領改正をリアルタイム同期。
2. **📐 ② 学科(一等)：計算ビジュアライザー ＆ 無限ランダム生成ドリル（全9公式）**
   - 定常旋回（旋回半径・荷重倍数）、第1フレネルゾーン半径、揚抗比・水平到達距離、バッテリー・風速ベクトル等の全9公式スライダー図解＋数値ランダム生成ドリル＋CBT画面内電卓。
3. **🗺️ ③ 実地：机上試験マップ演習（全6シナリオ・20点満点）**
   - 用紙A（飛行計画・飛行経路図）の矛盾点・法令違反・RTH高度不備・SORAリスク評価を検証し、用紙B（4問×5点）を採点するインタラクティブ演習。
4. **🎙️ ④ 実地：口述＆飛行日誌チェッカー（6場面×6日誌）**
   - 飛行前点検・異常事態・事故/重大インシデント報告の発声演習（100点持ち点減点方式）および飛行日誌3様式（全6ケース）の記入不備・60進法計算ミス検証。
5. **🚁 ⑤ 合格後：機体図鑑・実務判定・国交省ポータル（全10機種・14公的機関）**
   - 保有技能証明×機体認証区分×飛行空域からカテゴリー（Ⅰ/ⅡB/ⅡA/レベル3.5/Ⅲ）と許可承認要否・必須手続を即座に判定する実務シミュレーター。
   - 試験合格後のDIPS 2.0・運航実務5ステップロードマップ、型式認証機（PF2-CAT3 / E6150TC / Airpeak S1等）を含む実務ドローン10機種図鑑、国交省・DIPS 2.0・地理院DID・警察庁・防衛省・AIS JAPAN・総務省・JTSB・気象庁の公式14ポータルリンク集。
6. **🏫 ⑥ スクールROI・弱点分析・B2B管理（給付金＆LMS）**
   - 個人学習履歴からの弱点トップ3自動分析、買い切り合格パス（二等 ¥1,980 / 一等 ¥2,980）、「一発試験 vs 登録講習機関（教育訓練給付金・人材開発支援助成金対応）」ROI診断＆全国提携スクール資料請求、登録講習機関向け受講生10名管理クラウド（B2B LMS）。

### 6名の専門エージェント体制（Autonomous Multi-Agent Team）
- `kyosoku_general_expert` : 無人航空機教則全般（第1章〜第6章・版管理対応）・実地試験スペシャリスト
- `physics_sim_engineer` : 航空力学・一等計算全9公式シミュレーターエンジニア
- `fullstack_b2b_architect` : 個人買い切り決済・学習履歴弱点分析・B2BスクールLMSアーキテクト
- `growth_leadgen_strategist` : 一発試験vsスクールROI診断・全国提携スクール送客・SEOマーケター
- `kyosoku_qa_auditor` : 教則全般・法規ファクトチェック＆品質監査官
- `mlit_regulatory_watcher` : 国交省公式情報リアルタイム調査・サイト反映スペシャリスト

## ディレクトリ構成

├── index.html                                  # メインアプリケーションUI（6本柱モジュール＋国交省ウォッチャー統合）
├── styles.css                                  # コックピット計器風・高コントラストデザインシステム（Vanilla CSS）

│   ├── physics_engine.js                       # 一等計算ビジュアライザー全9公式＆無限ドリル

│   ├── b2b_monetize.js                         # 個人弱点分析・買い切り決済・B2B LMS管理

│   └── mlit-regulatory-watch.yml               # 国交省公式HP定期監視ワークフロー（GitHub Actions）
├── schema.sql                                  # PostgreSQL / Supabase マルチテナントDB設計
